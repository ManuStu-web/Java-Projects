A **desktop version of the classic Flappy Bird game** developed using **Java and Swing/AWT graphics**.  
This project recreates the fast-paced gameplay of the original mobile game using **basic animation, keyboard input handling, and collision detection**.

The player controls a bird that must fly through gaps between pipes without crashing.

---

## Project Overview

**Flappy Bird - Java Edition** is a simple 2D arcade-style game where the player must keep the bird flying by pressing a key to avoid obstacles.

The game demonstrates fundamental **game development concepts in Java**, including:

- Animation loops
- Keyboard input handling
- Collision detection
- Score tracking
- Graphics rendering using Java Swing

---

## Features

- Smooth animated gameplay
- Keyboard-based controls
- Randomly generated pipe obstacles
- Score tracking system
- Game over detection
- Classic Flappy Bird mechanics
- Lightweight desktop application

## How to Play

1. Run the game application.
2. Press **Spacebar** to make the bird fly upward.
3. Avoid hitting the **pipes** and the **ground**.
4. Pass through pipe gaps to stay alive.
5. Try to achieve the **highest score possible**.

---

## Example Controls

```
Spacebar → Bird jumps upward
Gravity → Bird falls downward
Avoid pipes to survive
```

## Installation & Setup

### 1 Clone the Repository

```bash
git clone https://github.com/ManuStu-web/Java-Projects.git
```

---

### 2 Open the Project

Open the project using any Java IDE:

- IntelliJ IDEA
- Eclipse
- VS Code

---

### 3 Ensure Images Are Available

Make sure the following images are present in the project folder:

- `flappybirdbg.png`
- `flappybird.png`
- `toppipe.png`
- `bottompipe.png`

These images are required for the game's graphics.

---

### 4 Run the Game

Run the following file:

```
App.java
```

The game window will open and gameplay will start.

---

## Example Gameplay Flow

1. Game window opens  
2. Bird appears on screen  
3. Pipes start moving across the screen  
4. Player presses **spacebar** to control the bird  
5. Game ends when the bird collides with a pipe
